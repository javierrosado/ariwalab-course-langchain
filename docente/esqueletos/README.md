## Uso en clase

- Revisar la sesión anterior y el checkpoint que trae cada equipo.
- Ejecutar las demos y comprobar los servicios necesarios antes del dictado.
- Planificar tres horas en vivo, incluyendo la pausa; comunicar aparte la franja de sustentación A1.
- Usar las rúbricas de cada evaluación y entregar checkpoints de recuperación cuando corresponda.
- Revisar la [preparación integral](VALIDACION-INTEGRAL.md) antes de iniciar la edición.
